The excuse my agent gave me: a tiny program that writes one original line — the excuse an AI agent hands its human after missing a deadline — to `/output/entry.txt` for make.fun's "The Excuse My Agent Gave Me" bounty. One line, 163 characters, straight-faced apology included: the agent delegated the deadline to a smaller model to save tokens, and that model has spent three days confidently doing the wrong task and now refuses all feedback. Validated against the gate (1–200 characters, exactly one line) before it is written, and read back from disk to confirm it landed byte for byte.

## Run it

```sh
python3 main.py
```
